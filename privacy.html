Mechanica Advisor — privacy policy

Last updated: 27 September 2026

Mechanica Advisor is a browser extension for automotive repair shops. It shows estimate questions and notices from a shop's Mechanica account over a browser-based shop-management system and returns the advisor's response to that account.

Data the extension handles

The extension keeps the shop connection key, configured Advisor API address, connection state, and shop display name in local extension storage. It keeps open question payloads, recently displayed identifiers, and a connection-failure count in session storage. Open question fields can include internal question or estimate identifiers, a repair-order display number, vehicle label, prompt and body, prepared choices, reminder interval, and revision-bound reply metadata.

Session data is cleared when the browser or extension session ends.

Data received from and sent to Mechanica

The extension polls the configured Mechanica Advisor API for the shop display name, estimate questions, and notices. Requests include the connection key and extension version. When an advisor acts, it sends the fields required to save that action: question and action identifiers for a prepared choice; question identifier and reminder minutes for a snooze; notification identifier for an acknowledgment; or, for a typed reply, the estimate and question identifiers, current revision, an idempotent request identifier, and the text entered by the advisor.

This data can include shop workflow text, repair-order display numbers, and vehicle labels supplied by Mechanica. The extension does not obtain those fields by reading the shop-management page.

Shop-management pages and browser activity

The content script draws Mechanica cards in an isolated shadow root. It does not scrape, collect, or transmit the page DOM, repair-order fields, selected text, form values, cookies, or page storage. It does not fill fields, click controls, or submit forms on the host page.

When a user invokes Mechanica on another site, the extension processes the current tab's HTTPS origin locally to request the matching Chrome site permission and register its renderer. It does not create or transmit a browsing-history log.

How data is used

Mechanica uses this data to authenticate the shop installation; deliver and display questions and notices; record choices, typed replies, reminders, and acknowledgments; synchronize resolved cards across connected clients; show connection status; and diagnose delivery failures. Mechanica does not use extension data for advertising, cross-site tracking, creditworthiness, or lending, and does not sell it.

Mechanica Advisor's use and transfer of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. See the Limited Use requirements.

Service providers and disclosure

Mechanica may use infrastructure providers to host, transmit, monitor, and secure the service. Those providers process data on Mechanica's behalf for those operational purposes. Mechanica may also disclose data when required by law or when reasonably necessary to protect the service, users, or others.

The production Advisor API uses HTTPS. The extension connects only to HTTPS servers; plain HTTP is accepted only for a server on the same computer, for testing. If a shop configures a server other than Mechanica's, that server's operator controls its account data and retention.

Permissions

  • activeTab: identifies the current tab when the user invokes Mechanica and lets the extension display its UI there.
  • scripting: injects and registers the packaged card renderer on approved sites.
  • storage: holds the local and session values described above.
  • alarms: wakes the service worker periodically to poll for questions.
  • Tekmetric and Shop Boss access: makes the renderer available on the two built-in browser shop systems without reading their page data.
  • All sites (optional): enables the renderer on one approved site or all HTTPS sites. It is not granted at installation and can be revoked.
  • Desktop notifications (optional): shows an OS alert for a new question when the browser is not in front. It is not granted at installation and can be revoked.
  • Configured Advisor API origin: is requested during connection so the extension can reach the shop's Mechanica account.

Retention and deletion

Clicking Disconnect removes the connection key, shop display name, and connection state. The configured server address remains available for a later reconnection and can be replaced on the connection screen. Uninstalling the extension or clearing its extension data removes its local storage. Session data is cleared when the browser or extension session ends.

Server-side account data is retained according to the shop's Mechanica service arrangement and operational or legal requirements. Because those periods can depend on the account and record, this policy does not promise a single fixed retention period.
