Extension Privacy Policy

Mechanica Advisor browser extension

Last updated August 25, 2026

Mechanica Advisor is a browser extension for automotive repair shops. It displays questions and notifications from a shop's own Mechanica account on top of the shop-management system the service advisor is already working in.

This policy covers the browser extension specifically. For the website and the wider service, see getmechanica.com/privacy.

The short version. The extension draws on top of your shop system. It never reads out of it. It stores your connection key on your own machine, talks to no server but Mechanica's, and contains no analytics, advertising, or tracking of any kind.

What the extension stores

Two values, in the browser's extension storage, on the advisor's own machine:

  • Connection key — the credential that identifies the shop's Mechanica account. Entered by the shop on the extension's options page.
  • Server address — which Mechanica server to talk to. Defaults to https://api.getmechanica.com/advisor.

Neither value is transmitted anywhere except to the Mechanica server named above, and neither is readable from any web page.

While the browser is running, the extension also keeps a short-lived list of question identifiers it has already displayed, so the same question is not shown twice. This is discarded when the browser closes.

What the extension does not do

  • It does not read, collect, or transmit the contents of any web page. The extension draws its cards on top of the page; it never reads out of it.
  • It does not track browsing history, page visits, or which sites are open.
  • It does not contain analytics, advertising, or third-party tracking of any kind.
  • It does not sell or share data with anyone. There are no third parties.

What is sent to Mechanica

Only the advisor's own answers, and only to the shop's own Mechanica account:

  • Which question was answered and which choice was picked.
  • That a question was snoozed, and for how long.
  • That a notification was dismissed.
  • The extension version, so support can tell the browser extension apart from the desktop application when a shop reports a problem.

These are sent to the server address configured above, authenticated with the shop's connection key.

Permissions, and why each exists

  • activeTab — read the current tab only at the moment the advisor clicks the Mechanica icon or presses Alt+M, so the extension knows which tab to draw in.
  • scripting — inject the card layer into the page, and register it to reappear on sites the shop has approved.
  • storage — hold the two values listed above.
  • alarms — check for new questions on a timer.
  • Your Mechanica server — requested when the shop connects, for that one address, so the extension can reach the shop's account.
  • All sites (optional) — never requested at install. Requested either for one site at a time, when the advisor first opens Mechanica on a shop system that is not built in, or for all sites at once if the shop turns that on from the options page. Either grant can be withdrawn at any time in the browser's settings or from the options page.
  • Desktop alerts (optional) — never requested at install. If the shop turns it on, the extension raises a desktop notification for a new question when the browser is not the window in front.

Data retention and deletion

The connection key and server address stay on the advisor's machine until they click Disconnect on the options page, or uninstall the extension. Either one removes them.
