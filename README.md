# Mechanica Advisor downloads

Installers for the Mechanica Advisor desktop app.

**Most people should not use this page.** Go to
[getmechanica.com/downloads](https://getmechanica.com/downloads), which picks the
right installer for your computer and walks through the install.

If you would rather grab a file directly, they are attached to the
[latest release](https://github.com/delanoklee/mechanica-advisor-releases/releases/latest):

| Your computer | File |
| --- | --- |
| Windows | `.exe` (recommended) or `.msi` for managed installs |
| Mac | `.dmg` (works on both Apple Silicon and Intel) |
| Linux | `.AppImage` or `.deb` |

## What this app does

Mechanica Advisor sits above whatever shop software you already run and turns a
finished inspection into a priced estimate. It works with desktop shop systems
such as RO Writer and Mitchell Manager SE as well as browser-based ones.

You will need a connection key from Mechanica to sign in. If you do not have one,
[book a demo](https://getmechanica.com).

## About this repository

This repository holds published installers only. It contains no source code. The
app itself is developed in a private repository; releases here are published
automatically by its build pipeline.
